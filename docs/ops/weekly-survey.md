# 周报问卷（每周五发，4 题）

> 投放工具：同上。2 分钟内能填完。
> 目的：捕捉主观体验 + 与客观指标交叉验证。
> 每位内测用户固定每周五 18:00 收到链接，连续 4 周。

---

## 第 1 题（单选 + 文字）

**本周你用了几次 Sage？主要用于什么场景？**
- 0 次（本周没用）
- 1~3 次
- 4~10 次
- 10 次以上

**用来做了什么？**（一句话）

## 第 2 题（文字）

**这周哪个功能或回答对你最有用？**
> 越具体越好。"行情查询"不够，是"查茅台 PE 时它顺便对比了五粮液和泸州老窖"。

## 第 3 题（文字）

**哪里最卡、最不满意、或者你直接放弃了？**
> 没有也没关系，回个"没"也行。但只要有，写出来——这是你最该修的清单。

## 第 4 题（量表 + 必填理由）

**0~10 分，你向同事朋友推荐 Sage 的可能性？**

> 0 = 完全不会，10 = 强烈推荐

**你打这个分的原因是？**（一句话）

## 与看板指标对照（每周一拉一次）

| 主观 | 客观（看板） | 差异时怎么办 |
|---|---|---|
| 周报 NPS 平均 | — | 单独记，主观 ≠ 客观 |
| "本周 0 次" 的比例 | DAU 实际分布 | 高比例 0 次 = 周报被忽略或产品没黏性 |
| "最有用"高频词 | `skill_used` Top | 高频词没出现在 skill 分布 = 用户在用你没埋点的能力 |
| "最卡"主题 | `error_logs` 类型 | 印证或发现新问题 |
| "放弃"场景 | 漏斗转化 | 兑换后没聊的比例 |

## 备注

- 收集到第 4 周时，所有"非常卡 / 0 分"的用户优先约访谈
- 单一问题重复出现的描述（如"不记得上次问了什么"）= 记忆 / 上下文问题优先级最高
- 周报回收后 24h 内回复，至少对回答了内容的用户说声"看到了"，让他们知道你真的在看
