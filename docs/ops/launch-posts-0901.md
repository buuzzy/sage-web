# 上线日执行手册

## 时间

- 工作日 12:00-13:00 或 20:00-22:00 发布效果最好
- 顺序建议：即刻 → V2EX → 朋友圈 → 小红书（即刻反馈最快，先验证文案）
- 每个平台发完 **30 分钟内守评论区**

## 今天看板节奏

| 时间点 | 看什么 | 信号与动作 |
|---|---|---|
| 发布后 1h | 注册/兑换数、漏斗注册→兑换转化 | 转化 < 60% = 注册流程有问题，自查注册页 |
| 每 2-3h | 各码用量（看板"兑换码管理"） | 某码用满 → 生成新码（改 note 续批次） |
| 发现异常 | 某码兑换量暴增 | 可能被搬运到别处 → 看板一键停用该码 |
| 睡前 | DAU、错误情况、群消息 | 记录今天数字，明天对照 |

## 错误监控

Supabase Studio → `error_logs` 表按 `created_at` 倒序，每小时扫一眼。
突增的同一 `error_type` = 优先修。

## 高频问题预案（评论区/群里大概率被问）

- "数据准吗？" → 行情来自第三方数据源，内测期仅供研究参考
- "会一直免费吗？" → 内测期免费，正式版会提前在群里说
- "支持 XX 市场/功能吗？" → 记下来，回复"排期中"——这就是需求清单
- "开源吗 / 下载桌面版？" → 目前仅 web，桌面端在规划中
